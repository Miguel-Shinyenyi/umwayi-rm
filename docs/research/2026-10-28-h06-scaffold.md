# 2026-10-28: H-06 scaffold design

Date: 2026-10-28. Source: written record of H-06 scaffold decisions (no prior response existed to quote). Purpose: research data for measurable outcomes. Status: notes, not results.

## Decisions

1. express serves the API. Conservative default, typed, enough for the contract's route list. No framework churn planned later.
2. Layout: src/app.ts builds the app, src/index.ts boots it, src/routes/ holds one module per route, src/adapters/ holds the model interface plus implementations, tests/ mirrors with vitest.
3. The model adapter interface bakes H-04 findings into types: reasoningEffort is the literal "low", defaults carry timeoutMs 60000 and seed 7. Callers cannot request default effort by construction.
4. FakeModelAdapter ships with the scaffold per experiments rule 8. Deterministic, offline, used by tests. The live Baseten adapter waits for H-09.
5. Tests never open sockets. The sandbox blocks listen, so handlers stay pure and directly tested. The wired route is proven by the compose healthcheck and the CI curl. This split is permanent, not a workaround to remove.
6. Compose runs api plus idle postgres:16 with healthchecks on both. Host port is API_PORT defaulting to 3000 so the stack coexists with the routine-machine stack on this machine.
7. CI runs install, typecheck, tests, build, compose up with wait, curl /health, and teardown. The compose step is the acceptance proof where local sandbox blocks apply.
8. Deps stay minimal and MIT or Apache-2.0 only, named in the README per the rules.

## How this is tested

H-06 acceptance is the CI curl on /health. Unit tests cover handler shape and fake determinism. Later tasks extend both layers.
