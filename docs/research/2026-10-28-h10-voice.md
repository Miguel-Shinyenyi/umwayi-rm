# 2026-10-28: H-10 voice intake and approval

Date: 2026-10-28. Source: written record of H-10 design decisions (no prior response existed to quote). Purpose: research data for measurable outcomes. Status: notes, not results.

## Decisions

1. Voice goes transcribe first. The H-04 audio FAIL cut direct audio intake, and the H-04 speech check proved the transcribe path. Intake accepts base64 WAV, transcribes, then runs the same loop as typed text.
2. The transcribe URL is `https://api.meta.ai/v1/asr/transcribe`. A live tone probe settled it: that shape returns HTTP 200, the doubled `/v1/v1/` variant returns 404. Response carries transcript plus audioDurationMs.
3. Intake runs synchronously and returns the run record: runId, modelId, transcript, outcome, proposals, turn count. No separate run table yet; the proposals plus the response are the record.
4. Approval is idempotent by proposal id and answers whether the entry already existed. The entry carries tier agent_proposed_approved and the proposal id.
5. The model-off fallback is a real route, not a message. POST /groups/:id/entries records a treasurer-confirmed entry directly, proven by a test where the fake model leaves the run unfinished and the manual entry still lands.
6. Proposal edit and question answer routes are not built. The acceptance checks did not need them, and the edit needs an audit home for the original payload that does not exist yet.

## Limitations

- Node has no network in the dev sandbox (curl works, node fetch gets ENOTFOUND; tsx fails with EPERM on listen). The compiled adapter was never live-run here, and no live speech-to-approval chain ran end to end. The wire shape is proven by curl plus the H-04 speech check; the wiring is proven by maintained tests with a stub transcriber and a scripted model. A networked run of the full chain is still open.

## How this is tested

Stubbed unit tests for the transcribe request shape, handler tests with mock requests over the memory store, and the approve-twice acceptance test. CI runs typecheck, the full suite including pg, build, and the compose health proof.
