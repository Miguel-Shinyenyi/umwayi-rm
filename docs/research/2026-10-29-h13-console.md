# 2026-10-29: H-13 console, Lab, seed and reset

Date: 2026-10-29. Source: written record of H-13 design decisions (no prior response existed to quote). Purpose: research data for measurable outcomes. Status: notes, not results.

## Decisions

1. The console is vanilla HTML, CSS, and JS with no build step, served from public/ by the existing express app. Fetch calls the same JSON routes the tests cover. The token lives in localStorage, never in a cookie or URL.
2. Styling follows the token table in the design log (amber accent, 18px card radius, system stack, sentence case, Demo data pill, focus rings) plus the taste preflight. Overdue uses badge text, never red. The footer carries the provisional Built with Muse Spark Open line.
3. The Lab chart reads /lab/runs, which summarizes committed run files. The lab script contains no typed scores; a test asserts the counted numbers appear nowhere in it.
4. Migrations run at boot when DATABASE_URL is set, and the image ships the pages, the pack, the run files, and the SQL. Compose runs demo mode with optional key passthrough; without keys the stack still serves everything except live model calls.
5. The design log describes a different product (candidates, interventions) and forced adaptation to the treasurer console. Its rewrite stays open; only the token and component discipline was reused.

## Limitations

- No chromium exists on this machine, so no page was rendered in a browser. HTTP reachability plus content markers are the checks. A human browser pass is still open.
- The compose proof ran from this tree, not from a literal fresh clone, because the branch is unpushed. The steps are exactly the README steps on clean volumes.
- Ports 3000 and 3100 were held by unrelated work, so the proof ran on 3200 via the documented API_PORT override. The other stacks were left untouched.

## How this is tested

Handler tests for seed, reset, group reads, today determinism, and lab summaries; static tests for page wiring, route calls, tokens, and the display line; node parse checks for both scripts; and the live compose proof above. CI runs typecheck, the full suite including pg, build, and the compose health proof.
